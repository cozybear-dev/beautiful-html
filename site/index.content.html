Hunt & Hackettbeautiful-html: example reports

Eight reports, each written by an agent from a short content file

Every page linked below is one self-contained HTML file. An agent wrote a few hundred lines of content and joined them to Hunt & Hackett's report kit. Open them, read their source, and ask your own agent for the next one.

This page is made the same way. All organisations, people and figures in the examples are invented, except where a report says otherwise.

Each one is built for its reader

Six of the eight tell one story: an intrusion at a freight company, and what followed. The same facts become a written report, a deck, a service review, a network review, a board brief and a budget proposal, because each reader needs something different from them.

{{CARDS}}

What every one of them does

  • It is one file

    Fonts, charts and data are inside it. It opens offline, makes no network requests, and can be emailed as it is.

  • It reads on a phone and prints on paper

    Narrow the window, or open the PDF beside any example: the same file, laid out again.

  • It moves for a reason, and stops when asked

    Figures draw in once; dots show direction; a reader who asks for reduced motion gets the final state.

  • It can be edited by whoever receives it

    The content sits at the top of the file with a short guide. "Source" under each example is that content.
