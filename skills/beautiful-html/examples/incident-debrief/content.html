Any one of three controls would have ended it

  1. Bind sessions to the device

    The stolen session would not have worked from the intruder's machine.

  2. Keep administrators off workstations

    There would have been no better credential to wait for.

  3. Rotate and vault service passwords

    The script on the file server would have held nothing of use.
