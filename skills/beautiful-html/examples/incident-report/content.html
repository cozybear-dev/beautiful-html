Hunt & HackettIncident report IR-2026-031

A stolen session became domain administrator in 41 hours

Between 14 and 16 September an intruder moved from one finance mailbox to the domain controller of Meridian Freight. Nothing in the path was an exploit: every step used access that was already allowed. The intruder was removed before any data left the network.

Prepared by Hunt & Hackett Incident Response for the CISO of Meridian Freight. 2 October 2026.

The intruder was fast at the end and patient in the middle

The whole intrusion took two days. Three quarters of that time was spent on one workstation, waiting for an administrator to sign in.

This report sets out the path the intruder took, the evidence for each step, why none of it raised an alarm for 41 hours, and the three changes that would have stopped it.

Five hops from a mailbox to the domain controller

Each hop used a credential that the previous system handed over. The five steps below take them one at a time.

Hour 0. A session is stolen

A finance clerk signs in on a page that looks like the company portal. The page relays the login to the real one, including the code from the authenticator app, and keeps the session cookie.

Eleven minutes later the same session is used from an address in another country.

Hour 2. A colleague opens a document

From the clerk's mailbox the intruder replies to a real thread with a spreadsheet. It comes from a known sender, about a known invoice, so a colleague opens it and enables its content.

The macro starts a remote-access tool on workstation WS-FIN-07.

Hour 32. An administrator signs in

For thirty hours the tool does nothing but check in. Then a file-server administrator signs in to WS-FIN-07 to fix a printer, and the intruder copies that sign-in from memory.

Hour 38. A password is found in a script

With the administrator's sign-in the intruder browses file server FS-02 and finds a backup script. The script holds the password of the account svc-backup in plain text. The password was set in 2019.

Hour 41. The directory is theirs

The backup account may replicate the directory. The intruder uses it to request the password data of every account, which is the same as holding the domain.

That request is the first thing in the whole path that raised an alert.

Thirty of the 41 hours passed on one workstation

The intruder touched five systems. On four of them the activity lasted a few hours at most. The long bar is the wait on WS-FIN-07, and it was the best chance to catch the intrusion: a remote-access tool was checking in every ten minutes, from a finance workstation, for more than a day.

How to read it

A bar is the time the intruder was active on a system. A dot is an event described in the path above. The dashed line is the first alert.

Any one of three controls would have ended it

The path had five hops, and it needed all of them. Each of the measures below removes one, at a different point and at a different cost.

  1. Bind sessions to the device

    The stolen session would not have worked from the intruder's machine. Stops the path at hour 0.

  2. Keep administrators off workstations

    There would have been no better credential to wait for. Stops it at hour 32.

  3. Rotate and vault service passwords

    The script would have held nothing of use. Stops it at hour 38.

  1. 16 Sep

    Contained

    Three accounts disabled, WS-FIN-07 isolated, directory password data reset twice.

  2. 30 Sep

    Service passwords rotated

    All 46 service accounts; 9 scripts with passwords in them rewritten.

  3. 31 Oct

    Device-bound sessions for finance and administrators

  4. 15 Dec

    Separate administration workstations in use

Decision needed

Extend device-bound sessions from 240 people to all 2,400 by March

Finance and administrators are covered by 31 October. Every other mailbox can still be used the way this one was.

What we did not find

No outbound transfer larger than 4 MB from any of the five systems, no new accounts, no changes to group policy, and no sign of the tool on any other workstation. Mail rules on the clerk's mailbox were unchanged.
